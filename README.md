## 👋 Hey, visitor!

I'm **Estevão**, a senior web developer who likes building things **properly, from the ground up** — custom WordPress themes without page builders, plugins with real architecture behind them, and PHP that follows the patterns instead of fighting them. Lately I've also been using **Python and LLMs** to tackle a problem every data person knows too well: data that's *there* but impossible to use.

Recruiter, developer, or just curious — make yourself at home. 🏠

- 🧱 **Currently building:** [BlogDynamic](https://github.com/estevaojneto/blogdynamic), the hand-made theme behind my blog
- 🤖 **Currently exploring:** LLM-based data cleaning and prompt-injection resistance
- ✍️ **Writing about:** tech, hiring, the industry, and inclusion at [0395.ch](https://0395.ch)
- 💬 **Ask me about:** WordPress internals, PHP design patterns, REST APIs, remote work
